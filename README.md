# Shivam Sah Portfolio

Responsive multi-page portfolio recreated from the supplied website screenshots.

## Pages
- Home
- About
- Educational Materials
- Gallery
- Contact Me

## Features
- Responsive desktop and mobile navigation
- Persistent **Dark Mode / Bright Mode** switch
- Search interaction
- Contact form that opens the visitor's email client
- GitHub Pages compatible
- Local image assets included

## Theme switch
The theme button is available in the header on every page. The selected mode is saved in the browser using `localStorage`, so the choice remains active when navigating between pages.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository settings.
